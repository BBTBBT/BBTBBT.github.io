## 四、如何查看

每个子文件夹里都是 `index.html`（自包含单文件，双击即可在浏览器打开）：

```
portfolio-archive/
├── README.md        ← 本说明
├── v8/index.html
├── v9/index.html
├── v10/index.html
└── v11/index.html
```

- 本地：直接双击对应 `index.html`。
- GitHub 上：可访问每个文件的 raw 链接查看（若仓库 Pages 已开启对应目录，也可走子路径）。
